# Process 13C spectra
## 1. Create processing config file
Within the downloaded data folder, make a new file called processing_13C.ini

This file holds the directory paths for the files you wish to process, as well as the name of the substrate that is labeled, and the
folder number where the run starts (generally around 21)

Ex. processing_13C.ini:

    [paths]
    #folder where all nmr runs will be stored on your machine
    project_dir=/home/christine/Dropbox/metabolic_modeling/nmr_runs/
    
    #relative path to the folder holding the peak position - metabolite correspondences to search for
    cfg_dir = ./cfgs/ 
    
    #relative path to the data files
    run_dir=./test/
    
    #identify the 13C labeled substrate
    cfg = mannitol.cfg
    
    #folder where processed results should be written
    output_dir= ./test/
    
    [data]
    #compound that was labeled with 13C
    labeled_substrate_name = mannitol
    
    isotope=13C
    
    #the folder number to start processing at
    run_start_num = 23
    
    [peak_selection]
    peak_method=ng_pick
    #higher number means less resolution and faster run-time. Acceptable range is 6-15
    r = 15
    manually_refine_curves = True
    show_curves = True
    prompt_continue = True


## 2. In a terminal, load environment.
Point to th environment you created in step 0
``` source ~/Documents/nmr-cdiff/nmr_cdiff_venv/bin/activate ```

## 3. Navigate to the folder with the processing scripts and start python session
```
cd Dropbox/metabolic_modeling/processing/process/
python3
```

## 4. Start processing: import the process script, and then create a stack object by to the processing_13C.ini file described in step 1.
Substitute the path to the processing_13C.ini file you made in step 1.
```
import process
s = process.Stack("../../nmr_runs/hrmas_13C_UMass_cells_112224/processing_13C.ini")
```

## 5. Calibrate the baseline
```
s.calibrate(overwrite = True)
```

    0. You should see a pop-up window showing a spectrum
    1. Slide the first slider to be in line with the right most peak
    2. Slide the last slider up until the right most peak's baseline is flat
    3. Slide the middle slider up until the left most peak's baseline is flat
    4. Close the popup window

*IF anything about the run looks off at this point, please check the function get_acquistion_parameters() in process.py. This function automatically populates a acquisition parameter file process_params.com, placed inside the run_dir supplied in the processing.ini configuration file. This has not yet been extensively tested with different NMR machines, with different people running the machines, and errors with peak location, spread, or noise are usually due to parameters that do not match between these scripts and the NMR machines*


## 6. Calibrate the reference peaks
A second window will automatically pop up

    1. Look up the 13C NMR spectrum for the labeled substrate (e.g. glucose, leucine, proline, mannitol) on HMDB. Select a peak to use as a reference. 
    
        For glucose, I use 63.549, which corresponds to teh rightmost peak
    
        For leucine, I use 26.826 which corresponds to the leftmost peak in the cluster of the rightmost 3 peaks
    
        For mannitol, I use 65.937 which corresponds to the rightmost peak. 

    2. Put this reference number in the top box. Then, using the cursor, hover over the center of the corresponding peak in the pop-up window. Use the magnifying glass button to draw a box around the peak to zoom in and get a more accurate answer. Look in the bottom righthand corner for x = ? to find the position of the experimental peak. Put this number in the bottom box, and click Submit.


## 7. Process peaks
Simply creates a "Spectrum" object for each spectrum in the processing pipeline, which will be used to store information about each spectrum
``` 
s.process_fids(overwrite = True)
```

## 8. Peak fit protocol
``` s.peakfit_fids(overwrite = True) ```

    In the processing_13C.ini config file created in step 1, you can specify desired parameters for the peakfitting process
    
    peak_method=ng_pick # other methods are not tested
    r = 13 # lower number means a lower noise threshold. Decrease to increase sensitivity, increase to speed up processing 
    manually_refine_curves = False # If True, a pop-up window will appear for each spectrum to allow manual adjustment of peaks.
    show_curves = False # If True, a pop-up window will appear to show each peak is labeled with which metabolite by the automatic protocol
    prompt_continue = False # If True, command line will prompt continue for each spectrum. Helpful for debugging

    A window will pop up for manual input if peaks are close to two different positions in the cfg reference file.

    * If you change parameters for the peak fit protocol at this point, you MUST rerun steps 4 - 7

## 9. Write out the peak areas
``` s.write_stack() ```

    Outputs file into the run_dir specificed in the processing config file from step 1.

    Area under the curve for each metabolite at each timepoint is written into the 'areas' tab



# Process 1H specra

## 1. Create processing config file
Within the downloaded data folder, make a new file called processing_1H.ini

This file holds the directory paths for the files you wish to process, as well as the name of the substrate that is labeled, and the
folder number where the run starts (generally around 21)

Ex. processing.ini:

    [paths]
    project_dir=/home/christine/Dropbox/metabolic_modeling/nmr_runs/
    cfg_dir = ./cfgs/
    run_dir=./hrmas_13C_UMass_cells_112224/
    output_dir= ./hrmas_13C_UMass_cells_112224/ 
    cfg = mannitol.cfg
    
    [data]
    labeled_substrate_name = mannitol
    isotope=1H
    run_start_num = 23

    [peak_selection]
    peak_method=ng_pick
    #higher number means less resolution and faster run-time. Acceptable range is 6-15
    r = 15
    manually_refine_curves = True
    show_curves = True
    prompt_continue = True



## 2. Start processing: import the process script, and then create a stack object by to the processing_1H.ini file described in step 1.

    ```
    s = process.Stack("../../nmr_runs/hrmas_13C_UMass_cells_112224/processing_13C.ini")
    ```

## 3. Calibrate
    s.calibrate()

    The tallest peak near the middle of the spectrum should be water. The reference position for this peak is 4.7. Calibrate in the same way as above

## 4. Process fids

    s.process_fids()

## 5. Ridge trace fids

    s.ridgetrace_fids()

    you must close each window for the next time step to continue

## 6. Output results into the run_dir specificed in the processing config file from step 1.
    s.write_stack(from_ridges = True)
