## Data Acquisition

Data may be located in one of two locations:
1. Dropbox: https://www.dropbox.com/$your_home_directory/NMR_Data
2. Server: /data/cctm/HRMAS_NMR

The data consists of 200-300 numbered folders. Each folder contains spectra with the following identifiers:
- `zgpg30` = 13C spectrum
- `noesypr1d` = 1H spectrum
- `hsqcphpr` = 1H-13C spectrum

## Processing 13C Spectra

### 1. Create Processing Configuration File

Create a file named `processing_13C.ini` in your downloaded data folder with the following structure:

```ini
[paths]
# Folder where all NMR runs will be stored
project_dir=/home/user/Dropbox/metabolic_modeling/nmr_runs/

# Relative path to the folder holding peak position - metabolite correspondences
cfg_dir = ./cfgs/

# Identify the 13C labeled substrate
cfg = mannitol.cfg

# Relative path to the data files
run_dir=./hrmas_13C_UMass_cells_112224/

# Folder where processed results should be written
output_dir= ./hrmas_13C_UMass_cells_112224/

[data]
isotope=13C

# The folder number to start processing at
run_start_num = 23

[peak_selection]
peak_method=ng_pick
r = 10
manually_refine_curves = True
show_curves = True
prompt_continue = True
```

**Configuration Notes:**
- See `data/cfgs/` for examples of configuration files. Each should contain the reference ppm shifts and names of expected chemicals (one per line, tab-separated).
- `isotope`: Should be one of `13C`, `1H`, or `13C_15N` reflecting the labeled isotope in the experiment. This determines analytical parameters based on `/scripts/process/isotopes.json`.
- `r`: Controls peak detection sensitivity. Higher values mean less resolution but faster run-time (acceptable range: 6-15). I usually use r = 6 for N15 runs, which need to be more sensitive to identify the shoulder, and r = 10 for regular 13C runs
- 'ng_peak' refers to the nmrglue (python package) peak pick function. This is the only peak picking method currently available and tested
- manually_refine_curves will allow the user to add in a peak, or adjust an existing peak fit to more closely match the data. If you find you must add or adjust peaks in the beginning of the run, chances are this will remain true for the entire run. Overreliance on this functionality will result in unreproducible data processing. Instead, decrease the r value to increase sensitivity and/or adjust the parameters within /scripts/process/isotopes.json


### 2. Run the Processing Script

Navigate to the processing scripts folder and start processing:

```bash
cd scripts/process/
python process.py --params_file ../../data/hrmas_13C_UMass_cells_012425/processing_13C.ini --calibrate --overwrite_peakfit
```

Use the following flags as needed:
- `--calibrate`: Overwrites existing baseline calibration
- `--overwrite_peakfit`: Overwrites existing AUC calculation. Otherwise, will only process unprocessed peaks

### 3. Baseline Calibration

When the first pop-up window appears showing a spectrum:
1. Align the first slider with the rightmost peak
2. Adjust the last slider until the rightmost peak's baseline is flat
3. Adjust the middle slider until the leftmost peak's baseline is flat
4. Close the popup window

> **Note:** If anything looks incorrect during this process, check the `get_acquistion_parameters()` function in `process.py`. This function automatically populates acquisition parameters in `process_params.com` within the specified `run_dir`. This functionality may require adjustments for different NMR machines.

### 4. Reference Peak Calibration

A second window will automatically appear for calibration:

1. Look up the 13C NMR spectrum for the labeled substrate on HMDB and select a reference peak:
   - For glucose: Use 63.549 (rightmost peak)
   - For leucine: Use 26.826 (leftmost peak in the cluster of the rightmost 3 peaks)
   - For mannitol: Use 65.937 (rightmost peak)

2. Enter the reference value in the top box
3. Hover over the center of the corresponding peak in the pop-up window
4. Use the magnifying glass to zoom in for more precision
5. Note the position value (x = ?) from the bottom right corner
6. Enter this experimental value in the bottom box and click Submit

### 5. Resolve Peak Discrepancies

The system will display peaks that overlap within 0.5 ppm for manual assignment:
1. Assign the correct peaks to their corresponding metabolites
2. Click Submit on each window as it appears

### 6. View Results

Results are output as an .xlsx file to the folder specified in the `output_dir` field of your `processing_13C.ini` file.
Results consist of:
    1. trace: human readable NMR data. Rows are the ppm, and columns are the value at that ppm for a given timepoint
    2. cfg: the ppm peak positions that were used to process with data
    3. area: area under the curve (summed over all peaks attributed to that metabolite) for each metabolite in the cfg. Each row is a timepoint
    4. area_percent: area under the curve for each metabolite divided by the total area under the curve for that spectrum

## Processing 1H Spectra

### 1. Create Processing Configuration File

Create a file named `processing_1H.ini` in your downloaded data folder:

```ini
[paths]
project_dir=/home/user/Dropbox/metabolic_modeling/nmr_runs/
cfg_dir = ./cfgs/
cfg = isocaproate.cfg
run_dir=./hrmas_13C_UMass_cells_112224/
output_dir= ./hrmas_13C_UMass_cells_112224/ 


[data]
isotope=1H
run_start_num = 23

[peak_selection]
peak_method=ng_pick
r = 15
manually_refine_curves = True
show_curves = True
prompt_continue = True
```

### 2. Run the Processing Script

```bash
cd scripts/process/
python process.py --params_file ../../data/hrmas_13C_UMass_cells_012425/processing_1H.ini --calibrate --peakfit
```
> **Note:** The tallest peak near 4.7ppm is water and can be calibrated to exactly 4.7ppm.
The goal of this script is simply to identify the timepoint at which isocaproate appears, so as to align multiple runs in time.

# Processing 13C-15N Spectra

### 1. Create Processing Configuration File

Create a file named `processing_13C_15N.ini` in your downloaded data folder:

```ini
[paths]
# Folder where all NMR runs will be stored
project_dir=/home/user/Dropbox/nmr-cdiff/data/

# Relative path to peak-metabolite correspondence files
cfg_dir = ./cfgs/

# Identify the 13C labeled substrate
cfg = alanine_n15.cfg

# Relative path to the data files
run_dir=./hrmas_13C_UMass_cells_012425/

# Folder where processed results should be written
output_dir= ./hrmas_13C_UMass_cells_012425/

[data]
isotope=13C_15N

# The folder number to start processing at
run_start_num = 21

[peak_selection]
peak_method=ng_pick
r = 6
manually_refine_curves = True
show_curves = True
prompt_continue = False
```
> **Important:** For 13C-15N spectra, use a smaller `r` value (around 6) to identify the shoulder caused by the 15N addition.


### 2. Run the Processing Script

```bash
cd scripts/process/
python process.py --params_file ../../data/hrmas_13C_UMass_cells_012425/processing_13C_15N.ini --calibrate --peakfit
```

> **Note:** The tallest peak near 4.7ppm is water and can be calibrated to exactly 4.7ppm.
You will need to manually attribute each peak to a type of Alanine (13C vs 15N vs. overlap/ignore). Use Fig 5. panel C from https://www.nature.com/articles/s41589-023-01275-9 to understand which peak belongs to which metabolite

# Adding a new modality
Currently supported NMR readout types are 13C, 1H, and 13C_1H. If you need to use another data modality, you must first
1. Add appropriate processing parameters in the scripts/process/isotope.json. These are largely determined from trial-error on what provides a good fit to the data.
2. Add an isotope label to the following section of process.py with an isotope label of your choice, and a pulse program that matches the keywords in the fid folders for the new data modality
```
def match_pulprog(isotope, pulprog):
    print("Matching: ", isotope)
    if isotope == '1H':
        return pulprog == 'noesypr1d'
    elif isotope == '13C':
        return pulprog == 'zgpg30'
        #return pulprog == 'noesyprigld1d'
    elif isotope == "13C_15N":
        return pulprog == "zgpg30"
    elif isotope == '1H_13C':
        return pulprog == 'hsqcphpr'
    return False
```


# Isotope.json
```
    "13C_15N": {
        "name": "Carbon-13",
        "fit_ppm_delta": 0.009,
        "fit_fwhm_max": 0.3,
        "fit_fwhm_min": 0.005,
        "peak_pick_msep": 0.015,
        "ppm_min": 0.0,
        "ppm_max": 200,
        "assignment_display_window": 1,
        "assignment_cluster_msep": 0.5,
        "fit_cluster_msep": 1,
        "fit_reach": 6
    }
```
Each data modality must be set up in /scripts/process/isotope.json with parameters for peak picking and peak fitting
- ppm_min/ppm_max: range of ppms to consider
- assignment_cluster_msep: the max distance between peaks that may be considered overlapped for user peak assignment
- assignment_display_window: the ppm range of the window pop-up for user peak assignment
- peak_pick_msep: minimum separation between peaks needed to be considered separate peaks
- fit_ppm_delta: distance from peak center that will be considered for the curve fit (AUC calc)
- fit_fwhm_max: maximum width of the curve fit
- fit_fwhm_min: minumum width of the curve fit
- fit_reach: dictates region around peak to fit (nmrglue.analysis.linesh.fit_spectrum(box_width = fit_reach))
