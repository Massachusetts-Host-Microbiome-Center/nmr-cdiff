# Process 13C spectra
## 1. Create processing config file
Within the downloaded data folder, make a new file called processing_13C.ini

This file holds the directory paths for the files you wish to process, as well as the name of the substrate that is labeled, and the
folder number where the run starts (generally around 21)

Ex. processing_13C.ini:
```
    [paths]
    #folder where all nmr runs will be stored on your machine
    project_dir=/home/christine/Dropbox/metabolic_modeling/nmr_runs/
    
    #relative path to the folder holding the peak position - metabolite correspondences to search for
    cfg_dir = ./cfgs/ 
    
    #relative path to the data files
    run_dir=./test/
    
    #identify the 13C labeled substrate
    cfg = mannitol.cfg
    
    #folder where processed results should be written
    output_dir= ./test/
    
    [data]
    #compound that was labeled with 13C
    labeled_substrate_name = mannitol
    
    isotope=13C
    
    #the folder number to start processing at
    run_start_num = 23
    
    [peak_selection]
    peak_method=ng_pick
    #strength of peak detection: higher number means less resolution and faster run-time. Acceptable range is 6-15
    r = 15
    manually_refine_curves = True
    show_curves = True
    prompt_continue = True
```


## 2. In a terminal, load the environment you installed in step 0.
``` 
source ~/Documents/nmr-cdiff/nmr_cdiff_venv/bin/activate 
```

## 3. Navigate to the folder with the processing scripts and start processing
Use the --calibrate flag to overwrite existing baseline calibration if it exists. Use --peakfit flat to overwrite existing AUC calculation if it exists
```
cd scripts/process/
python process.py --params_file ../../data/hrmas_13C_UMass_cells_012425/processing_13C.ini --calibrate --peakfit
```

    0. You should see a pop-up window showing a spectrum
    1. Slide the first slider to be in line with the right most peak
    2. Slide the last slider up until the right most peak's baseline is flat
    3. Slide the middle slider up until the left most peak's baseline is flat
    4. Close the popup window

*IF anything about the run looks off at this point, please check the function get_acquistion_parameters() in process.py. This function automatically populates a acquisition parameter file process_params.com, placed inside the run_dir supplied in the processing.ini configuration file. This has not yet been extensively tested with different NMR machines, with different people running the machines, and errors with peak location, spread, or noise may be due to parameters that do not match between these scripts and the NMR machines*


## 6. Calibrate the reference peaks
A second window will automatically pop up

    1. Look up the 13C NMR spectrum for the labeled substrate (e.g. glucose, leucine, proline, mannitol) on HMDB. Select a peak to use as a reference. 
    
        For glucose, I use 63.549, which corresponds to teh rightmost peak
    
        For leucine, I use 26.826 which corresponds to the leftmost peak in the cluster of the rightmost 3 peaks
    
        For mannitol, I use 65.937 which corresponds to the rightmost peak. 

    2. Put this reference number in the top box. Then, using the cursor, hover over the center of the corresponding peak in the pop-up window. Use the magnifying glass button to draw a box around the peak to zoom in and get a more accurate answer. Look in the bottom righthand corner for x = ? to find the position of the experimental peak. Put this number in the bottom box, and click Submit.

## 7. Resolve discrepancies
Peaks that overlap within 0.5 ppm will be displayed for the user to assign which peaks belong to which metabolites. Assign the correct peaks, then click submit on each window as it appears

## 8. Results are output to the folder specified in processing_13C.ini's "outdir" field

# Process C13_N15 spectra:

## 1. Create processing config file
Within the downloaded data folder, make a new file called processing_13C_15N.ini

**Note**: r must be much smaller here, to regularly identify the shoulder caused by the 15N addition
Ex. processing_1H.ini:
```
    [paths]
    #folder where all nmr runs will be stored on your machine
    project_dir=/home/christine/Dropbox/nmr-cdiff/data/

    #relative path to the folder holding the peak position - metabolite correspondences to search for
    cfg_dir = ./cfgs/
    #identify the 13C labeled substrate
    cfg = alanine_n15.cfg

    #relative path to the data files
    run_dir=./hrmas_13C_UMass_cells_012425/
    #folder where processed results should be written
    output_dir= ./hrmas_13C_UMass_cells_012425/

    [data]
    #compound that was labeled with 13C
    labeled_substrate_name = mannitol

    isotope=13C_15N

    #the folder number to start processing at

    prompt_continue = False
```

## 2. In a terminal, load the environment you installed in step 0.
