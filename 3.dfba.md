    1. output_folder: full path to the folder where results will be output
    2. model_file: full path to the file with the organisms genome-scale cobra model (.json) to be used
    3. experiments: should point to the current folder which holds nmr run data
    4. products: should contain the known downstream products of the metabolite in question
        Mannitol(mnl1p): Acetate (ac), Alanine (alaL), Ethanol(eto)
        Glucose(glc): Acetate (ac), Alanine (alaL), Ethanol(eto)
        Leucine(leuL): Isocaproate(isocap)
        Proline(proL): 5-aminovalerate(5apn)
        - Each product has an associated model_id which must be a valid metabolite id in the genome-scale cobra model from model_file
        - Each product must include a keyword for the shape of the curve expected to fit (i.e. logistic)
        - Each product must incude the number of carbons that are in that molecule. This is used in standard_curves.py to filter out low-signal peaks. The ratio of the total area attributed to a metabolite / the number of carbons must be above a threshold
    5. standard_peaks: full path to the NMR data from run standards
    6. standard_concentrations: full path to the true concentrations that were run for the standard
    7. tracked_reactions: Reactions whose flux you want reported particularly from the dfba. There will also be a table that includes predicted fluxes of all reactions
    8. tracked_metabolites: Metabolites whose input and output reactions you want reported particularly from the dfba.
    9. reactions_to_delete: reactions listed here will be removed from the model completely. This is used for simulating knockouts
    10. Media composition: each media component requires a user-given name, and model_id that matches that metabolite in the genome-scale cobra model, and the concentration of that metabolite in the media. NOTE the media is set once at the beginning of the script, before DFBA begins. Timesteps in the dFBA DO NOT update the media availability. This could be an improvement for future iterations.

    * Note: if you only want trajectories, you only need to be concerned about the values for items 1 (output_folder) 3 (experiments) 4(products) 5(standard_peaks) and 6(standard_concentrations)

    * Note: there is currently no way to run the dfba without standard curves, as this would not truly make sense without a conversion from area under the NMR peaks to concentration (we need to be able to compare relative concentrations of metabolites for the data to be useful in constraining an FBA). For mannitol runs, b/c we lack standard curves, I had copied the standard curve values for Glucose in ../../nmr_runs/standards/13CGlc_standards/



## 2. Run the dfba by pointing to this configuration file
    ```
    cd ~/processing/process
    python dfba.py --cfg_path ../../nmr_runs/hrmas_13C_UMass_cells_112224/dfba_cfg.json
    ```

Optionally, run only the piece to obtain metabolite trajectory curves
	```
	cd ~/processing/process
	python dfba.py --params_file ../../nmr_runs/hrmas_13C_UMass_cells_112224/dfba_cfg.json --trajectory_only
	```

Either of these options will output two files into the output folder/results/
	- time_norm_areas.csv : data transformed by the standard curve (available in nmr_runs/standards/), and aligned with the beginning of isocaproate formation from the 1H NMR data 
	- logistic_met_collect.csv : the parameters of the logistic curve fit to the data for each metabolite
