## 1. Obtain PBI genome:
    - Obtained strain DSM14991 as discussed in [text](https://pubmed.ncbi.nlm.nih.gov/34637781/)
    - output: data/cell_host_microbe_paper/genome/pbi_DSM14991_NZ_AVNC01000001.fna

## 2. Annotate genome:
    - Use KBASE to annotate the genome
    - output: data/cell_host_microbe_paper/genome/rast/rast_annotation.json

## 3. Build model:
    - Use the KBASE portal to build the model
    - output: data/cell_host_microbe_paper/genome/models/RAST.gff_genome.mdl.json/RAST.gff_genome.mdl.json
    - notes: 
        - there is NO gapfilling in this step. The reason is that while KBASE will allow you to choose a 'gram positive' template for biomass-based gapfilling, there's a bug such that it will actually use gram negative instead. Also, we want finer-grained control over the gapfilling process, so we do this in the next few steps

## 4. Gapfill the PBI model from C. diff curated model:
    - notes:
        - C. diff model is highly manually curated, however, it used the BiGG vocabulary, which does not always have an easy translation to the modelSEED vocabulary. In order to effectively compare and port reactions from our curated model to the new model, we need to convert.
        - there exists a non-trivial conversion from BiGG universe of reactions and metabolites to modelSEED universe. check scripts/metabolic_models/working_w_seed_models.py getConversionFromCdiff() for details
    - output: 
        - results/pbi_model_gapfill/bifermentans_gapfilled_from_cdiff.json # cobra model with gapfill reactions and gene rules added
        - results/pbi_model_gapfill/reactions_added_all.csv # csv of reactions added. If there is a gene rule toave the justify, the PBI annotation will have the named enzyme. Elsewise it will be empty.
        - results/pbi_model_gapfill/bifermentans_gapfilled_from_cdiff.pkl # The complete model object from "working_w_seed_models.py"
    - script: 
        - python scripts/metabolic_models/gapfill_from_cdiff.py  --params_file build_pbi_model.ini

## 5. Add reactions from metabolomics:
    -script:
        - python scripts/metabolic_models/integrating_metabolomics.py --params_file build_pbi_model.ini
        - python scripts/metabolic_models/add_metabolomics_reactions.py --params_file build_pbi_model.ini
    -output: 
        - results/pbi_model_gapfill/compounds_to_be_utilized_metabolomics.csv # metabolites to be added to the model
        - results/pbi_model_gapfill/compounds_to_be_added_metabolomics.csv # metabolites to be added to the model
    - notes:
    Metabolites are considered is they are significantly increased or decreased (rank sum test, p < .05) in PBI vs. GF condition in mice (n=8 for each group). Before testing, each sample is divided by the median of all its metabolites for sample-wise normalization, and values are log transformed. Metabolites that are increased in PBI are labeled 'produced and metabolites that are decreased in PBI are labeled 'utilized'. Biosynthetic/catabolic pathways are then research manually and found in reactions_added_metabolomics.ods and reactions_added_metabolomics.csv
